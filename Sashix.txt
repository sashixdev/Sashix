Sashix (v1.0 Legacy)
Sashix — лёгкая 32-битная графическая операционная система с собственным ядром sasKernel, оконным менеджером, встроенным компилятором приложений .sas и поддержкой Dual Boot.

Аппаратные требования


Компонент	Минимальные	Рекомендуемые
Архитектура и CPU	Любой 32-битный x86-совместимый процессор (Intel 80386 / 486 и новее, без требований к SSE/MMX)	Pentium III / Core 2 Duo или современный x86_64 процессор от 500 МГц
Оперативная память (RAM)	32 МБ (для размещения ядра, двойного буфера экрана и кэша медиаплеера)	64 МБ и выше
Видеосистема (GPU)	Видеоадаптер с поддержкой VESA BIOS Extensions (VBE 2.0+) и линейного фреймбуфера (LFB)	Видеокарта с поддержкой VBE 1280x720 или 1024x768 (24/32-бит)
Накопитель (Storage)	10 МБ на жёстком диске или флеш-накопителе с интерфейсом IDE / ATA (режим PIO)	32–64 МБ на IDE/ATA диске для записи видео с экрана и хранения пользовательских файлов
Устройства ввода	Клавиатура и мышь с интерфейсом PS/2 (или USB с активной эмуляцией Legacy USB в BIOS)	Стандартные контроллеры PS/2
Звук	Системный динамик (PC Speaker)	Материнская плата с распаянным спикером или эмулятор с поддержкой pcspk
Прошивка (Firmware)	Классический Legacy BIOS	Legacy BIOS или UEFI с включённым модулем совместимости CSM


Ключевые возможности релиза

• Умный загрузчик (Zet Boot Manager): автоматическое обнаружение других ОС на дисках (Windows Boot Manager, Ubuntu, Arch Linux) для Dual Boot и скрытое меню разработчика по клавише S (счётчик FPS и Debug Log действий в реальном времени).
• Интерактивный установщик: выбор языка интерфейса (Русский / English), разметка и форматирование диска в SashixFS v2 или FAT32, создание профиля с защитой паролем.
• Графическая среда и софт: полупрозрачные окна, экран блокировки, редактор и компилятор Sapp Edit для создания программ на языке .sas, программный 3D-движок, игра Snake и терминал с поддержкой прав ROOT.
• Встроенный захват экрана: создание скриншотов (Ctrl + C) и запись видео с рабочего стола (Ctrl + V) прямо на диск.


Sashix — Обзор возможностей системы (v1.0)

Sashix — самописная 32-битная графическая операционная система на базе собственного ядра sasKernel, написанная на C и Assembly (NASM) с нуля без использования сторонних библиотек и стандартной библиотеки C.

1. Многоступенчатый загрузчик и Dual Boot (Zet Boot Manager)

• Поддержка LBA и CHS: Загрузчик автоматически определяет возможности BIOS (INT 13h Extensions) и корректно грузит ядро как на современных машинах, так и на старом железе через геометрию диска.
• Умный Dual Boot: При включении система сканирует подключённые диски и разделы, распознаёт по сигнатурам другие ОС (Windows Boot Manager, Ubuntu, Arch Linux, GRUB и др.) и позволяет передать им управление через Chainloading.
• Меню разработчика (S при загрузке):
	• Sashix (FPS Monitor): Выводит на панель задач счётчик кадров в секунду в реальном времени для замера производительности.
	• Sashix (Debug Action Log): Отображает живой лог каждого действия пользователя (клики, горячие клавиши, запуск окон, операции с диском) для быстрой отладки.
• Verbose Boot (Лог инициализации ядра): Построчный вывод диагностики оборудования при старте — проверка вендора процессора (CPUID), объёма ОЗУ из CMOS, таблицы прерываний IDT, дисков ATA0 и маппинга видеопамяти VESA.

2. Интерактивный установщик и файловые системы

• Полноценный мастер установки: Запускается автоматически при первом старте на чистом диске и сохраняет конфигурацию прямо в загрузочный сектор (MBR).
• Двуязычный интерфейс: Выбор языка системы (Русский или English) и переключение раскладки клавиатуры на лету клавишей F6.
• Выбор и форматирование ФС: Поддержка разметки раздела и физического форматирования диска в родную SashixFS v2 или совместимую FAT32 с визуальной полосой прогресса.
• Профиль и безопасность: Создание учётной записи пользователя с возможностью установить пароль для экрана блокировки и защиты системных файлов.

3. Графическая оболочка и интерфейс (GUI)

• VESA Linear Framebuffer: Работа в высоком разрешении (1280x720 / 1024x768) с автоматической адаптацией под 24-битный и 32-битный цвет и двойной буферизацией (back_buf) для плавной отрисовки без мерцания.
• Эффекты полупрозрачности: Отрисовка окон, меню «Пуск», панели задач и контекстного меню с программным альфа-блендингом и скруглёнными углами.
• Двуязычный рендеринг шрифтов: Встроенный растровый шрифт с полной поддержкой кириллицы (UTF-8) и латиницы.
• Система уведомлений: Всплывающие системные уведомления в углу экрана о событиях, ошибках и действиях программ.
• Экран блокировки: Защита рабочего стола паролем при загрузке и отображение актуального времени из аппаратных часов реального времени (RTC CMOS) с учётом выбранного часового пояса.

4. Встроенные приложения

• Sapp Edit (IDE и компилятор): Встроенная среда разработки со встроенным компилятором собственного языка программирования .sas. Позволяет писать код, собирать исполняемые файлы в /Apps и мгновенно запускать их по клавише F5.
• 3D Engine: Программный трёхмерный движок на чистом CPU без GPU-ускорения — вращение и управление 3D-моделью в пространстве (WASD, Space, +/-).
• Sashix Terminal: Многофункциональная командная строка со встроенным полноэкранным текстовым редактором NSA, пасхалкой matrix и аппаратной диагностикой.
• Files (Файловый менеджер): Навигация по системным директориям (/Sashix, /Users, /Apps, /Media), запуск .sas программ, просмотр медиафайлов и импорт приложений с внешнего USB / Slave накопителя.
• Media Player: Встроенный просмотрщик изображений (.jpg) и видеоплеер (.mp4) с аппаратным чтением кадров напрямую с диска.
• Settings (Настройки): Изменение цвета рабочего стола, регулировка программной яркости экрана, громкости системного динамика и часового пояса.
• Snake: Классическая аркадная игра «Змейка» с подсчётом очков.

5. Встроенный захват экрана и медиа

• Скриншоты (Ctrl + C): Мгновенный захват текущего кадра рабочего стола, сжатие в RGB565 и сохранение в папку /Media в формате .jpg.
• Запись видео с экрана (Ctrl + V): Запись происходящего на экране в реальном времени с индикатором REC на панели задач. Запись продолжается до остановки пользователем или до полного заполнения свободного места на диске с автоматическим сохранением в .mp4.

6. Команды терминала и горячие клавиши


Основные команды Sashix Terminal

• help — список всех доступных команд.
• dirls / cd <папка> — просмотр содержимого и переход по каталогам.
• cr dir <имя> / cr file <имя> / rm <имя> — создание папок, файлов и их удаление.
• cat <файл> — вывод содержимого файла в терминал.
• nsa <файл> — запуск встроенного текстового редактора (Esc — сохранить и выйти).
• su <пароль> — повышение привилегий до уровня ROOT (Ring 0) для доступа к защищённым системным файлам.
• sysinfo — чтение реальных данных о процессоре (CPUID) и объёме оперативной памяти (CMOS).
• hostinfo — чтение реальной информации о материнской плате (SMBIOS / PCI Host) и модели накопителя (ATA IDENTIFY).
• sasfast — вывод сводки о системе в стиле Neofetch.
• speak <текст> — озвучивание текста через аппаратный динамик PC Speaker.
• matrix — запуск матричного скринсейвера.
• panic — принудительный вызов экрана паники ядра (BSOD) для отладки.
• rboot / power — аппаратная перезагрузка или выключение питания ПК (ACPI / PS/2).

Системные горячие клавиши

• F6 — переключение раскладки клавиатуры (RUS / ENG).
• Alt — открыть или закрыть меню «Пуск».
• ПКМ (Правая кнопка мыши) — контекстное меню с быстрым запуском программ и буфером обмена.
• Ctrl + A / Ctrl + S — копировать / вставить текст через системный буфер обмена.
• Ctrl + C — сделать скриншот экрана.
• Ctrl + V — начать или остановить запись видео с экрана.
• Win + D — открыть терминал.
• Win + R — открыть файловый менеджер.
• Win + Ctrl + B — открыть настройки.
• Win + A — свернуть/закрыть все открытые окна.
• Alt + C + A + X — открыть окно инспектора регистров процессора (CPU REGISTERS).
• Alt + D + X — экстренная перезагрузка системы.

7. Безопасность и отказоустойчивость

• Обработка исключений CPU (IDT): Перехват аппаратных сбоев процессора (деление на ноль, недопустимая инструкция, ошибка защиты, Page Fault) с выводом экрана SASHIX KERNEL PANIC и дампом всех регистров (EIP, EAX, EBX, ECX, EDX, ESP, EBP).
• Разграничение прав (USER / ROOT): Системные файлы в /Sashix защищены от случайного удаления или перезаписи обычным пользователем.
